Developer & Customization Guide

Local Tagging Rules & Pluggable LLM / AI Adapters

Every book added to Book Rotation passes through a two-tier enrichment pipeline managed by TaggingService: (1) Deterministic Local Rules (fast, offline, multilingual, enabled by default) and (2) Optional AI Enrichment Adapters (strictly opt-in, falling back cleanly to local rules whenever offline).

1. What Are the Local Tagging Rules & How Do They Work?

Online book catalogs often return noisy BISAC categories such as "Juvenile Fiction / General" or "Ficción Infantil" instead of child-meaningful themes like bedtime, dinosaurs, emotions, or autumn. The local rule engine runs completely offline in <1 ms per book:

  1. Diacritic Normalization (stripDiacritics): Converts accented characters (á → a, ñ → n, ù → u) so patterns match English, Spanish, Italian, and French titles/synopses uniformly.
  2. Catalog Noise Stripping (NOISE_WORDS): Removes generic labels like juvenile fiction, picture books, cuentos infantiles, and albo illustrato.
  3. Curated Topic Matching (TAXONOMY_RULES): Tests combined title + subtitle + summary + provider subjects against word-bounded regular expressions to emit normalized lowercase tags (up to 8 clean tags per book).
  4. Age & Stage Refinement (inferStageAndAgeCues): Detects explicit cues like "board book / cartonato", "level 1 reader / primeros lectores", or "ages 3–5", plus page-count heuristics, and generates a human-readable readingLevelHint.

2. Where Do the Tagging Files Live?

File Path Responsibility
src/features/tagging/rule-tagger.js Contains NOISE_WORDS, TAXONOMY_RULES, inferStageAndAgeCues(), buildReadingLevelHint(), and enrichBookWithLocalRules().
src/features/tagging/ai-tag-adapter.js Defines the AiTagEnrichmentAdapter interface plus the built-in browser-prompt-api (on-device window.ai) and custom-endpoint (HTTPS/localhost webhook) adapters.
src/features/tagging/tagging-service.js Orchestrates Local Rules + optional AI enrichment, timeout budgets, adapter registry, and safe fallbacks.

3. How to Add or Change Local Topic Rules

Open src/features/tagging/rule-tagger.js and locate the exported TAXONOMY_RULES array. Because text is passed through stripDiacritics() before matching, write all regex keywords in plain ASCII lowercase: 

// src/features/tagging/rule-tagger.js
export const TAXONOMY_RULES = [
  // Add your custom family topic near the top for priority:
  {
    tag: 'music',
    pattern:
      /\b(music|musical|orchestra|piano|guitar|violin|drums?|singing|songs?|lullab(?:y|ies)|musica|canciones|canzoni|strumenti)\b/i,
  },
  {
    tag: 'gardening',
    pattern:
      /\b(garden|gardening|seeds?|compost|vegetables?|orchard|huerto|jardin|semillas|orto|giardino)\b/i,
  },
  // ...existing rules (christmas, winter, animals, dinosaurs, trucks, emotions, bedtime, etc.)
];
Applying Updated Rules to Existing Books: After editing TAXONOMY_RULES, open Settings → Tagging & Optional AI Enrichment and tap Re-Enrich (N books). Every book in your library will immediately pick up your new topic rules while preserving custom tags you added by hand!

4. Customizing Reading Stage & Age Heuristics

In the same file (src/features/tagging/rule-tagger.js), inspect inferStageAndAgeCues(input, normalizedCorpus) to adjust how page counts and format keywords map to board-book (ages 0–3), picture-book (ages 2–6), early-reader (ages 5–8), and chapter-book (ages 7–12). Run npm test after making changes to verify all tagging assertions pass.

5. Adding a New LLM / AI Enrichment Adapter

There are two ways to connect an LLM (such as Gemini, Ollama, or OpenAI via your own server proxy) without ever putting API keys in browser code:

Approach A — Zero Code Changes (Use Built-in Custom Proxy Webhook)

In Settings → Tagging & Optional AI Enrichment, enable Optional AI-Assisted Tag Enrichment, select Custom Keyless Proxy / Local Bridge, and point it at a local bridge (e.g. http://localhost:8787/enrich) or server route (/api/enrich-book) that accepts a POST JSON body ({ book: TaggingBookInput }) and returns: 

{
  "tags": ["bedtime", "bears", "friendship", "winter"],
  "ageMin": 2,
  "ageMax": 5,
  "readingStage": "picture-book",
  "readingLevelHint": "Ages 2–5 · Picture book · Gentle rhythmic read-aloud"
}

Approach B — Registering a First-Class Adapter in Code

To add a dedicated selectable card in Settings, implement the AiTagEnrichmentAdapter contract in src/features/tagging/ai-tag-adapter.js (or a new module) and register it on TaggingService: 

// Example: src/features/tagging/ollama-local-adapter.js
import { parseLooseJsonObject } from './ai-tag-adapter.js';
import { sanitizeTagList, VALID_READING_STAGES } from './rule-tagger.js';

/** @returns {import('./ai-tag-adapter.js').AiTagEnrichmentAdapter} */
export function createLocalOllamaAdapter(endpoint = 'http://localhost:11434/api/generate') {
  return {
    id: 'local-ollama',
    label: 'Local Ollama (Llama / Gemma)',
    transportKind: 'on-device',
    privacyNote: 'Runs locally on your machine via localhost:11434; zero cloud traffic.',

    checkAvailability() {
      const isLocal =
        typeof location === 'undefined' ||
        location.hostname === 'localhost' ||
        location.hostname === '127.0.0.1';
      return isLocal
        ? { available: true, reason: 'Ready to query local Ollama daemon on port 11434.' }
        : { available: false, reason: 'Only available when running on localhost.' };
    },

    async enrichBook(input, { signal }) {
      const prompt = [
        'Return strict JSON {"tags":[...],"ageMin":2,"ageMax":6,"readingStage":"picture-book","readingLevelHint":"..."}',
        `Title: ${input.title}`,
        `Authors: ${(input.authors || []).join(', ')}`,
        `Summary: ${input.summary || ''}`,
      ].join('\n');

      const res = await fetch(endpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ model: 'gemma2:2b', prompt, stream: false, format: 'json' }),
        signal,
      });
      if (!res.ok) throw new Error(`Ollama HTTP ${res.status}`);
      const data = await res.json();
      const parsed = parseLooseJsonObject(data.response || '{}');

      return {
        tags: sanitizeTagList(Array.isArray(parsed.tags) ? parsed.tags : [], 8),
        ageMin: typeof parsed.ageMin === 'number' ? parsed.ageMin : undefined,
        ageMax: typeof parsed.ageMax === 'number' ? parsed.ageMax : undefined,
        readingStage: VALID_READING_STAGES.has(String(parsed.readingStage))
          ? /** @type {any} */ (parsed.readingStage)
          : undefined,
        readingLevelHint:
          typeof parsed.readingLevelHint === 'string' ? parsed.readingLevelHint : undefined,
      };
    },
  };
}

Then register your adapter during store/service initialization:

// Inside createBuiltInAiAdapters() in src/features/tagging/ai-tag-adapter.js
// or at runtime via store.getTaggingService().registerAdapter(createLocalOllamaAdapter());
