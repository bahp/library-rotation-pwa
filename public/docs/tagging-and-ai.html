Local Tag Rules, Presets & AI

Every book is tagged instantaneously offline by deterministic keyword rules, then matched against seasonal & milestone presets—with zero cloud dependency required.

Example: Book → Tags Add a Topic Tag Add a Collection Preset Optional AI Adapter

1. How Local Tagging Works

src/features/tagging/rule-tagger.js scans a book’s title, synopsis, publisher categories, format, and page count to assign tags and reading stage offline.

Input Book Metadata Goodnight, Goodnight, Construction Site
Pages: 32 · Format: Board Book
Categories: “Juvenile Fiction / Bedtime & Dreams / Trucks”
→
Rule Tagger Output Stage: Toddler (1–3y) · Ages 1–4
bedtime vehicles rhyming
File What you edit there
src/features/tagging/rule-tagger.js TAXONOMY_RULES keyword lists + age/stage inference rules.
src/data/rotation-presets-config.js Built-in seasonal, holiday, milestone, and everyday shelf presets.
src/features/tagging/ai-tag-adapter.js Optional AiTagEnrichmentAdapter webhook or custom tagger.

2. Example — Add a New Topic Rule (e.g. dinosaurs)

Open src/features/tagging/rule-tagger.js and add an entry to TAXONOMY_RULES:

// src/features/tagging/rule-tagger.js
const TAXONOMY_RULES = [
  // ...existing rules...
  {
    tag: 'dinosaurs',
    keywords: [
      'dinosaur',
      'dinosaurs',
      't-rex',
      'triceratops',
      'prehistoric',
      'fossil',
      'dinosaurio', // multilingual keywords work out of the box!
    ],
  },
];

Tip: Manual tags you type or delete on a book card are never overwritten by automatic re-tagging.

3. Example — Add a Seasonal Collection Preset

Presets never hardcode book titles—they describe topic preferences, count, swap cycle, cooldown, deterministic seed, and optional MM-DD start date so shelves build from each family’s own library. Add one in the UI (Rotations → Presets → + Add Preset) or in src/data/rotation-presets-config.js: 

// src/data/rotation-presets-config.js
{
  id: 'preset-world-space-week',
  title: 'Space & Stargazing Week',
  description: 'Rockets, planets, astronauts, and curious night-sky adventures.',
  category: 'traditions-events',
  preferredTags: ['space', 'stem', 'bedtime', 'curiosity'],
  count: 5,
  swapDays: 10,
  cooldownDays: 21,
  varietyMix: true,
  deterministicSeed: 'preset:world-space-week',
  suggestedStartMonthDay: '10-04', // Alerts every Oct 4 + shows countdown in #/presets (omit for Anytime)
}

4. Optional AI / Webhook Enrichment

AI enrichment is off by default. You can connect a private HTTPS webhook in Settings → AI Tagging or pass a custom AiTagEnrichmentAdapter in code:

POST Payload Sent 
{
  "title": "El Monstruo de Colores",
  "authors": ["Anna Llenas"],
  "existingTags": ["Spanish"]
}
→
JSON Response Returned 
{
  "tags": ["emotions", "colors"],
  "readingStage": "preschool",
  "ageMin": 2,
  "ageMax": 5
}
/** @type {import('./src/features/tagging/ai-tag-adapter.js').AiTagEnrichmentAdapter} */
const myCustomAdapter = {
  id: 'local-classifier',
  label: 'Custom Classifier',
  isAvailable(settings) {
    return Boolean(settings.aiTaggingEnabled);
  },
  async enrichBook(book) {
    return { tags: ['emotions'], confidence: 0.92, source: 'local-classifier' };
  },
};
