Developer Architecture & Custom Catalog Providers

Book Rotation is engineered as a lightweight, zero-framework-bloat ES Module TypeScript/JSDoc application styled with Tailwind CSS v4, backed by an IndexedDB persistence adapter and an optional Express server proxy (server.ts).

1. Codebase Directory Map

2. Rendering & Zero-Flash DOM Reconciliation

Views are pure functions of state ((props) => htmlString), making every screen fast to unit-test in Node without a heavy browser DOM harness. At runtime, patchRootHtml(rootEl, nextShellHtml) in src/ui/dom-patch.js reconciles live DOM nodes by key (id, data-book-card, data-backdrop-action) and adopts/hydrates media elements (<video>) cleanly.

3. How CatalogService Queries & Merges Providers

  1. catalogService.lookupByIsbn(rawIsbn) normalizes any ISBN-10 or ISBN-13 into canonical 13-digit ISBN.
  2. All enabled providers run concurrently via Promise.allSettled—a timeout or HTTP 429 on one provider never blocks the remaining providers.
  3. mergeBookCandidates() in src/features/catalog/normalizer.js combines hits, preferring verified titles, high-resolution HTTPS covers, complete page counts, unioned topic tags, and full sources[] provenance (so the UI displays whether a book came from Google Books, Open Library, or both).
  4. If an ISBN edition lacks cover art in all providers, findSiblingCoverUrl() automatically searches sibling printings of the same title + author to recover a verified cover image.

4. Step-by-Step: Adding a New Book Catalog Metadata Provider

Every catalog provider implements the MetadataProvider contract defined in src/features/catalog/catalog-service.js: 

/**
 * @typedef {Object} MetadataProvider
 * @property {string} id          - Stable kebab-case ID (e.g. 'library-of-congress')
 * @property {string} label       - Human-readable name shown in Settings & attribution
 * @property {(isbn13: string, options?: { retainRaw?: boolean, signal?: AbortSignal }) => Promise<BookCandidate | null>} lookupByIsbn
 * @property {(input: { query: string, author?: string }, options?: { retainRaw?: boolean, signal?: AbortSignal, limit?: number }) => Promise<BookCandidate[]>} searchBooks
 */

Example: Creating src/features/catalog/providers/loc-provider.js

import { normalizeProviderRecord } from '../normalizer.js';

/**
 * @param {ReturnType<typeof import('./http-client.js').createHttpClient>} httpClient
 * @returns {import('../catalog-service.js').MetadataProvider}
 */
export function createLibraryOfCongressProvider(httpClient) {
  return {
    id: 'loc-catalog',
    label: 'Library of Congress Catalog',

    async lookupByIsbn(isbn13, options = {}) {
      const url = `https://www.loc.gov/books/?q=${encodeURIComponent(isbn13)}&fo=json&c=5`;
      const payload = await httpClient.getJson(url, { signal: options.signal });
      const first = Array.isArray(payload?.results) ? payload.results[0] : null;
      if (!first) return null;

      return normalizeProviderRecord({
        provider: /** @type {any} */ ('loc-catalog'),
        externalId: String(first.id || isbn13),
        title: String(first.title || ''),
        authors: Array.isArray(first.contributor) ? first.contributor : [],
        isbn13,
        publishedDate: String(first.date || ''),
        subjects: Array.isArray(first.subject) ? first.subject : [],
        coverUrl: Array.isArray(first.image_url) ? first.image_url[0] : undefined,
        raw: options.retainRaw ? first : undefined,
      });
    },

    async searchBooks({ query, author }, options = {}) {
      const q = [query, author].filter(Boolean).join(' ');
      const limit = options.limit || 8;
      const url = `https://www.loc.gov/books/?q=${encodeURIComponent(q)}&fo=json&c=${limit}`;
      const payload = await httpClient.getJson(url, { signal: options.signal });
      const rows = Array.isArray(payload?.results) ? payload.results : [];

      return rows
        .filter((item) => item && item.title)
        .map((item) =>
          normalizeProviderRecord({
            provider: /** @type {any} */ ('loc-catalog'),
            externalId: String(item.id || item.title),
            title: String(item.title),
            authors: Array.isArray(item.contributor) ? item.contributor : [],
            publishedDate: String(item.date || ''),
            subjects: Array.isArray(item.subject) ? item.subject : [],
            coverUrl: Array.isArray(item.image_url) ? item.image_url[0] : undefined,
            raw: options.retainRaw ? item : undefined,
          })
        );
    },
  };
}

Wiring Your New Provider Into the App

  1. Register in CatalogService: Add createLibraryOfCongressProvider(client) to the default providers list in src/features/catalog/catalog-service.js (or call catalogService.registerProvider(...) in src/main.js).
  2. Expose Toggle in Settings: Add 'loc-catalog' to DEFAULT_SETTINGS.enabledMetadataProviders in src/core/seed.js and to the catalogProviders list in src/features/settings/settings-view.js.
  3. Attribution Badge (Optional): Add a display label/icon entry in src/ui/components/provider-attribution.js.
