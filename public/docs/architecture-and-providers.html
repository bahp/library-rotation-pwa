Developer & Configuration Guide

Everything a maintainer or developer needs to know about Little Shelf: centralized config files, the 4-corner badge taxonomy, rotation math, offline IndexedDB storage, and localization.

1. End-to-End Data Flow

Scan / Search → CatalogService (Parallel Providers) → Merge & Deduplication → RuleTagger (Taxonomy) → Store (IndexedDB) → patchRootHtml() (DOM diff)
  • No cover flicker: src/core/dom-patch.js diffs live DOM nodes in place so unchanged <img> book covers never unmount or re-fetch on navigation.
  • Deterministic rotation generation: Both manual shelf generation and #/presets collections run through a seeded PRNG (src/features/rotations/rotation-engine.js) for reproducible tests and predictable shelf swaps.
  • 100% Client-Side Privacy: Zero user data leaves the phone. IndexedDB persists catalog, profile, and rotation collections offline.

2. Centralized Configuration Directory (/src/config/)

All configurable app behaviors, styling palettes, collection presets, numeric boundaries, and language dictionaries are unified inside /src/config/. This makes customizing the app clean and straightforward without editing core component code.

File What it configures & How to edit
/src/config/colors-and-badges.js Defines the 4-corner cover overlay slots (COVER_BADGE_SLOTS), avatar color tones (AVATAR_TONES), cloth-bound book spine fallback palettes (BOOK_SPINE_PALETTES_BY_KEY), and CSS styling maps for catalog badges and rotation adornos.
/src/config/presets.js Contains the 15+ curated collection presets (DEFAULT_ROTATION_PRESETS) including Winter Holidays, Ramadan, First Day of School, Bedtime Calm, and Potty Training, with target book counts, swap days, cooldown days, and annual MM-DD start dates.
/src/config/play-apps.js Configures the Storytime Randomizer and Book Hunt cards in #/play, including app IDs, titles, descriptions, SVG icons, and optional custom logo / illustration URLs.
/src/config/defaults.js Default constants: initial child profile age settings, safe numeric boundaries (NUMERIC_BOUNDS: book count, swap days, cooldown days), and default AppSettings.
/src/config/i18n.js Isomorphic localization loader and formatting helper (t(lang, key, replacements)) supporting English (en), Spanish (es), and Italian (it).
/src/config/locales/ Raw YAML locale dictionaries: en.yaml (English default), es.yaml (Spanish), and it.yaml (Italian).

3. Cover Badge Taxonomy Specification

Book covers use 4 fixed, non-overlapping corner slots defined in src/config/colors-and-badges.js: 

export const COVER_BADGE_SLOTS = Object.freeze({
  catalogState: {
    slot: 'catalog-state',
    corner: 'top-left',
    exclusive: true,
    positionClass: 'pointer-events-none absolute top-1.5 left-1.5 z-20',
  },
  affection: {
    slot: 'affection',
    corner: 'top-right',
    exclusive: false,
    positionClass: 'pointer-events-none absolute top-1.5 right-1.5 z-20',
  },
  rotationState: {
    slot: 'rotation-state',
    corner: 'bottom-left',
    exclusive: true,
    positionClass: 'pointer-events-none absolute bottom-1.5 left-1.5 z-20',
  },
  owners: {
    slot: 'owners',
    corner: 'bottom-right',
    exclusive: false,
    positionClass: 'pointer-events-none absolute bottom-1.5 right-1.5 z-20',
  },
});

Top-Left: Catalog State (Mutually Exclusive)

Shown only when a book has an exceptional catalog state:

  • Wishlist: Not yet owned; shopping idea.
  • Loan: Borrowed from a public library or friend.
  • Saved: Saved / interested.
  • Torn / Broken / Retired: Physical condition flag.

Standard Owned + Good rotatable books leave this slot empty.

Bottom-Left: Rotation & Usage (Mutually Exclusive)

Strict priority resolution on rotatable books when badges are enabled:

  1. ✓ Read: Solid green checkmark (read on active shelf).
  2. ⏱ Shelf Xd: Solid amber (on active shelf >= stale days & unread).
  3. ▤ Shelf: Dark pill (currently out on active shelf).
  4. ⏱ Rest Xd: Amber tint (resting in box cooldown with X days left).
  5. ✦ New: Sky pill (never rotated on any shelf yet).
  6. ✓ Read (light): Off-shelf book read together in past cycle.

4. YAML Locale Dictionaries (en.yaml, es.yaml, it.yaml)

All user interface strings are stored in human-readable YAML files inside /src/config/locales/. To add or update translations:

  1. Open src/config/locales/en.yaml, es.yaml, or it.yaml.
  2. Edit or add the key path under the relevant namespace (e.g. home.myNewFeature).
  3. Use {placeholder} for variables (e.g. readSummary: "{completed} of {total} read").
  4. In your UI code, call t(lang, 'home.myNewFeature', { placeholder: value }).
Note on Book Titles: Book titles, author names, and ISBNs stay in their original publication language. The locale files translate navigation, headings, badges, and instruction text.

7. Rotation Engine Math & Variety Penalties

When Little Shelf generates a shelf, candidate books are scored using 4 weighted heuristics in src/features/rotations/rotation-engine.js:

  • Age Fit (0 to +30 pts): Proximity between child age and the book's target age band.
  • Theme & Tag Relevance (0 to +25 pts): Matches against rotation objectives or preset tags.
  • Cooldown Penalty (-100 pts): Heavy exclusion penalty if rotated within the cooldown window (e.g. past 14–30 days).
  • Unseen Diversity Bonus (+15 pts): Books that have never been placed on a shelf (✦ New) or haven't been seen in the longest time receive priority.
