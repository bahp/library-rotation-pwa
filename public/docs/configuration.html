Book Lookup & Quotas

Google Books Setup

Little Shelf queries Open Library + Google Books in parallel and merges both results. Choose the setup that matches where you run the app.

Which Mode Fits You? Get a Free Google Key Option A: Local / Node (.env) Option B: Cloudflare Worker (5 Min) How Merging & Sync Work Play Logos & Home Screen PWA

1. Pick Your Setup

Where you run Little Shelf What works out of the box Optional upgrade for international ISBNs
Just trying it / English books Open Library works immediately with zero setup. None needed unless Spanish, Catalan, French, Italian, or German barcodes miss.
Local development / Docker / Desktop Open Library works immediately. Add GOOGLE_BOOKS_API_KEY to .env (Option A).
Phone browser / Saved to Home Screen (PWA) / GitHub Pages Open Library works immediately. Deploy a 5-minute personal Cloudflare Worker proxy (Option B).

2. Get a Free Google Books API Key (1 Minute)

  1. Go to the Google Cloud Console — Books API and log in with any Google account.
  2. Click Enable.
  3. Go to Credentials → Create Credentials → API Key.
  4. Copy your key (e.g. AIzaSy...). It includes 1,000 free queries per day, which is more than enough for family library scans.

3. Option A: Local Development / Node Server (.env)

If you run Little Shelf via npm run dev on your laptop, the local Express server already acts as a secure server-side proxy so your API key is never exposed to the browser.

  1. Create or edit .env in the project root: 
    GOOGLE_BOOKS_API_KEY=AIzaSyYourKeyHere
  2. Restart your dev server: npm run dev
  3. Open Settings → Catalog Metadata Providers. The diagnostic will automatically verify the key and display a green checkmark.

4. Option B: Personal Phone Proxy via Free Cloudflare Worker (5 Minutes)

Why a proxy is needed on static phone hosts: Browsers block direct client-side requests to Google Books when an API key is attached to prevent credentials from being stolen. A lightweight serverless proxy forwards barcode queries safely without exposing your key to visitors.

Step 1: Create a Free Cloudflare Account

Sign up at dash.cloudflare.com (free forever, no credit card required). Go to Compute (Workers & Pages) → Workers → Create Application → Create Worker.

Step 2: Paste Your Worker Code

Click Quick Edit and replace the code with this secure proxy handler:

export default {
  async fetch(request, env) {
    const origin = request.headers.get('Origin') || '*';
    const allowed = env.ALLOWED_ORIGIN || '*';
    const corsHeaders = {
      'Access-Control-Allow-Origin': allowed === '*' ? '*' : origin,
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type',
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders });
    }

    const url = new URL(request.url);
    const targetUrl = new URL('https://www.googleapis.com/books/v1/volumes');
    url.searchParams.forEach((val, key) => targetUrl.searchParams.set(key, val));

    if (env.GOOGLE_BOOKS_API_KEY) {
      targetUrl.searchParams.set('key', env.GOOGLE_BOOKS_API_KEY);
    }

    const response = await fetch(targetUrl.toString(), {
      headers: { 'User-Agent': 'LittleShelf-Proxy/1.0' }
    });

    const body = await response.text();
    return new Response(body, {
      status: response.status,
      headers: { ...corsHeaders, 'Content-Type': 'application/json' }
    });
  }
};

Click Save and Deploy.

Step 3: Add Your Environment Variables

In your Worker dashboard, go to Settings → Variables and Secrets:

  • Add GOOGLE_BOOKS_API_KEY = your Google API key (click Encrypt).
  • Add ALLOWED_ORIGIN = your hosted site URL (e.g. https://yourname.github.io) or leave as *.

Step 4: Copy Your Proxy URL

Copy your worker URL (e.g. https://books-proxy.yourname.workers.dev). Open Little Shelf on your phone, go to Settings → Catalog Metadata Providers → Custom Proxy URL, paste it, and tap Save & Verify.

5. How Google Books & Open Library Merge + Updating Existing Books

  • Parallel Lookup: When both providers are enabled (the default), barcode scans and searches query Google Books and Open Library concurrently via Promise.allSettled.
  • Field Priority & Union: When both find an edition, Google Books serves as the primary record (title, high-resolution cover thumbnail, summary, page count) while Open Library fills any missing fields and contributes archival subject headings so topic tags combine the best of both catalogs.
  • Retroactive Library Sync: If you scanned books earlier using Open Library only and configure Google Books later, open Settings → Catalog Metadata Providers → Update Existing Library with Google Books to enrich existing books with Google Books covers, page counts, tags, and dual provenance without changing your owners, shelf status, or custom photos.

6. Customizing Play App Logos, Preview Images & Home Screen PWA

The Play tab (#/play) showcases preview cards for Storytime & Topic Picker and Book Hunt (“Find It!”) that open smoothly as bottom sheets when tapped. You can swap their logos, preview illustrations, titles, or CTA labels in one file:

  • Configuration file: src/data/play-apps-config.js
  • Static image folder: Drop any square logo (1:1) or landscape preview image (16:10 / 4:3) into public/assets/play/ and reference it as 'assets/play/your-image.jpg' (no leading slash so GitHub Pages subpaths work automatically).
  • Vector-only mode: Set logoUrl: '' or imageUrl: '' if you prefer clean built-in SVG icons ('dice', 'compass', 'sparkles', 'books').
// src/data/play-apps-config.js
export const PLAY_APPS_CONFIG = Object.freeze([
  Object.freeze({
    id: 'storytime-picker',
    title: 'Storytime & Topic Picker',
    imageUrl: 'assets/play/storytime-picker-preview.jpg',
    logoUrl: 'assets/play/storytime-picker-logo.jpg',
    logoIcon: 'dice',
    ctaLabel: 'Open Storytime Picker',
  }),
  // ...
]);

Saving as a Phone Home Screen App (PWA): Tap Settings → Installable Phone App (PWA) → Save to Home Screen (or use the compact Home Screen banner on the Shelf page). On Android Chrome/Edge this triggers the native one-tap install dialog; on iPhone/iPad Safari it opens step-by-step Share → Add to Home Screen instructions.
