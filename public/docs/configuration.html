Google Books Setup

Little Shelf queries Open Library + Google Books in parallel and merges both results. Choose the setup that matches where you run the app.

1. Pick Your Setup

Where you run Little Shelf What works out of the box Optional upgrade for international ISBNs
Just trying it / English books Open Library works immediately with zero setup. None needed unless Spanish, Catalan, French, Italian, or German barcodes miss.
Laptop or self-hosted Node server Express proxies /api/books/* automatically. Add GOOGLE_BOOKS_API_KEY in a local .env file (Option A).
Static GitHub Pages / Phone PWA Browser queries Open Library + public Google Books directly. Deploy a free Cloudflare Worker in under 5 minutes and paste its URL in Settings (Option B).
Never commit your own API key to a public GitHub repo Anything inside VITE_* or committed source files is visible to every visitor and shares your personal daily quota. Keep keys in untracked .env files or a private Worker secret.

2. Get a Free Google Books Key (60 Seconds)

1

Enable Books API

In Google Cloud Console, create a project and click Enable on Books API.

2

Create Credentials

Open APIs & Services → Credentials → + Create Credentials → API key.

3

Restrict to Books API

Under API restrictions, choose Restrict key and check Books API only → Save.

4. Option B — GitHub Pages / Phone PWA (Cloudflare Worker in Under 5 Minutes)

When running as a static PWA (like GitHub Pages) or hitting browser CORS / shared-IP restrictions, setting up a free Cloudflare Worker proxy is the cleanest solution. Here is the complete, step-by-step guide to deploying your Cloudflare Worker proxy in under 5 minutes.

1

Step 1: Create a Free Cloudflare Account & Open Workers

Go to cloudflare.com and log in or create a free account. In the Cloudflare dashboard sidebar, click Workers & Pages → Create application → Create Worker, name it (e.g. books-proxy), and click Deploy. (Don’t worry about the template code yet; we will replace it next.)

2

Step 2: Paste Your Worker Code

Once deployed, click Edit code to open Cloudflare’s in-browser editor. Delete whatever default code is inside index.js (or worker.js), paste the exact Worker script below, and click Save and deploy in the top right. 

export default {
  async fetch(request, env) {
    const origin = request.headers.get('Origin') || '';
    const cors = {
      'Access-Control-Allow-Origin': env.ALLOWED_ORIGIN || origin || '*',
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
    };
    if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: cors });

    const incoming = new URL(request.url);
    const upstream = new URL('https://www.googleapis.com/books/v1/volumes');
    for (const key of ['q', 'maxResults', 'printType']) {
      if (incoming.searchParams.get(key)) upstream.searchParams.set(key, incoming.searchParams.get(key));
    }
    if (env.GOOGLE_BOOKS_API_KEY) upstream.searchParams.set('key', env.GOOGLE_BOOKS_API_KEY);

    const res = await fetch(upstream.toString(), { headers: { Accept: 'application/json' } });
    return new Response(await res.text(), {
      status: res.status,
      headers: { ...cors, 'Content-Type': 'application/json; charset=utf-8' },
    });
  },
};
3

Step 3: Add Your Environment Variables & Secrets

To keep your Google API key safe and lock down who can use your proxy, go back to your Worker’s main dashboard page (Workers & Pages → select books-proxy) → Settings tab → Variables & Secrets:

  • Plain Variable: Name ALLOWED_ORIGIN, Value: your PWA’s URL (e.g. https://yourname.github.io or http://localhost:5173 for local testing).
  • Encrypted Secret: Name GOOGLE_BOOKS_API_KEY, Value: paste your actual Google API key (starting with AIzaSy...).

Click Save / Deploy to apply the changes.

4

Step 4: Copy Your Proxy URL & Connect It

Back on your Worker summary page, copy your assigned workers.dev URL (e.g. https://books-proxy.yourname.workers.dev). Open your PWA on your phone or browser → Settings → Catalog Metadata Providers → expand Advanced (Optional): Custom Books Proxy Server URL, paste your Worker URL into Personal Phone PWA Books Proxy URL, and tap Save & Verify.

Verification: You will immediately see a green confirmation box and a ✓ tick on Check Google Books API confirming your app is routing queries securely through your serverless proxy!

5. How Google Books & Open Library Merge + Updating Existing Books

  • Parallel Lookup: When both providers are enabled (the default), barcode scans and searches query Google Books and Open Library concurrently via Promise.allSettled.
  • Field Priority & Union: When both find an edition, Google Books serves as the primary record (title, high-resolution cover thumbnail, summary, page count) while Open Library fills any missing fields and contributes archival subject headings so topic tags combine the best of both catalogs.
  • Retroactive Library Sync: If you scanned books earlier using Open Library only and configure Google Books later, open Settings → Catalog Metadata Providers → Update Existing Library with Google Books to enrich existing books with Google Books covers, page counts, tags, and dual provenance without changing your owners, shelf status, or custom photos.

6. Customizing Play App Logos, Preview Images & Home Screen PWA

The Play tab (#/play) showcases preview cards for Storytime & Topic Picker and Book Hunt (“Find It!”) that open smoothly as bottom sheets when tapped. You can swap their logos, preview illustrations, titles, or CTA labels in one file:

  • Configuration file: src/data/play-apps-config.js
  • Static image folder: Drop any square logo (1:1) or landscape preview image (16:10 / 4:3) into public/assets/play/ and reference it as 'assets/play/your-image.jpg' (no leading slash so GitHub Pages subpaths work automatically).
  • Vector-only mode: Set logoUrl: '' or imageUrl: '' if you prefer clean built-in SVG icons ('dice', 'compass', 'sparkles', 'books').
// src/data/play-apps-config.js
export const PLAY_APPS_CONFIG = Object.freeze([
  Object.freeze({
    id: 'storytime-picker',
    title: 'Storytime & Topic Picker',
    imageUrl: 'assets/play/storytime-picker-preview.jpg',
    logoUrl: 'assets/play/storytime-picker-logo.jpg',
    logoIcon: 'dice',
    ctaLabel: 'Open Storytime Picker',
  }),
  // ...
]);

Saving as a Phone Home Screen App (PWA): Tap Settings → Installable Phone App (PWA) → Save to Home Screen (or use the compact Home Screen banner on the Shelf page). On Android Chrome/Edge this triggers the native one-tap install dialog; on iPhone/iPad Safari it opens step-by-step Share → Add to Home Screen instructions.
