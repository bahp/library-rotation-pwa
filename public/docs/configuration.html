Configuration & Quota Security

Google Books API & GitHub Pages Setup

Book Rotation queries two independent book catalogs in parallel—Google Books and Open Library—merging titles, authors, page counts, subject headings, and cover artwork into one enriched record.

1. Open Library vs. Google Books Coverage

  • Open Library (Zero Setup): Works immediately everywhere (including static GitHub Pages) with no account or key. Strongest for English-language picture books and classic ISBNs.
  • Google Books Public Volumes API: Adds significantly broader international coverage (Spanish, Italian, French, German, Catalan, regional printings) and high-resolution publisher thumbnails. Without a dedicated credential, Google applies a shared anonymous IP rate limit (HTTP 429).

2. Security: Why Raw API Keys Are Never Saved in Public Browser Storage

Important Maintainer Note for Public GitHub Pages Deployments:
1. Never commit your own API key into a public repository—anyone visiting your site would share and exhaust your daily quota.
2. Typing raw API keys directly into browser localStorage or URL query parameters (?key=...) exposes the secret in browser history, DevTools network logs, Service Worker caches, and any browser extension. Instead, Book Rotation uses a leak-free server/Worker proxy pattern so every user keeps their own quota private.

3. Create a Free Credential in Google Cloud Console (60 Seconds)

  1. Open the Google Cloud Console — Books API Library and click Enable.
  2. Go to APIs & Services → Credentials → click + Create Credentials → API key.
  3. Under API restrictions, select Restrict key and check only Books API, then click Save.

4. Option A — Local Development, Node, Docker, or Cloud Run

When running Book Rotation via its built-in Express server (server.ts), create an untracked .env file in the project root (copied from .env.example): 

# .env (git-ignored — never committed)
GOOGLE_BOOKS_API_KEY=your_google_books_credential_here

Restart the server (npm run dev or npm start). The frontend calls /api/books/volumes; server.ts injects your credential upstream on the server and strips it from all responses. Open Settings → Check Google Books API to confirm Google Books Server Key Configured.

5. Option B — Public GitHub Pages + Per-User Phone PWA Proxy

If you deploy the static PWA to GitHub Pages, your deployment has no server key—so visitors never consume your quota. Any user (including you on your own iPhone/Android PWA) who wants dedicated Google Books quota can deploy a free Cloudflare Worker (100,000 free requests/day) in two minutes:

  1. Create a free Worker at Cloudflare Dashboard → Workers & Pages.
  2. In the Worker’s Settings → Variables and Secrets, add a Secret named GOOGLE_BOOKS_API_KEY containing your restricted Google Books credential.
  3. Paste this Worker script and click Deploy (replace ALLOWED_ORIGIN with your GitHub Pages domain, e.g. https://yourname.github.io, or * for personal testing):
export default {
  async fetch(request, env) {
    const ALLOWED_ORIGIN = '*'; // Or lock to 'https://your-username.github.io'
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        status: 204,
        headers: {
          'Access-Control-Allow-Origin': ALLOWED_ORIGIN,
          'Access-Control-Allow-Methods': 'GET, OPTIONS',
        },
      });
    }

    const incoming = new URL(request.url);
    const upstream = new URL('https://www.googleapis.com/books/v1/volumes');
    for (const [k, v] of incoming.searchParams.entries()) {
      if (k.toLowerCase() !== 'key') upstream.searchParams.set(k, v);
    }
    if (env.GOOGLE_BOOKS_API_KEY) {
      upstream.searchParams.set('key', env.GOOGLE_BOOKS_API_KEY);
    }

    const res = await fetch(upstream.toString(), {
      headers: { Accept: 'application/json' },
    });

    return new Response(res.body, {
      status: res.status,
      headers: {
        'Content-Type': 'application/json; charset=utf-8',
        'Access-Control-Allow-Origin': ALLOWED_ORIGIN,
      },
    });
  },
};
  1. Open Book Rotation on your phone → Settings → Catalog Metadata Providers → paste your keyless HTTPS Worker URL (e.g. https://my-books-proxy.yourname.workers.dev/volumes) into Personal Phone PWA Books Proxy URL and tap Save on Device.
  2. This URL is saved only on that phone and is automatically excluded when exporting JSON library backups.
