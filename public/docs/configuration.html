Google Books Setup

Little Shelf queries Open Library + Google Books in parallel and merges both results. Choose the setup that matches where you run the app.

Which Mode Fits You? Get a Free Google Key Option A: Local / Node (.env) Option B: GitHub Pages + Phone

1. Pick Your Setup

Where you run Little Shelf What works out of the box Optional upgrade for international ISBNs
Just trying it / English books Open Library works immediately with zero setup. None needed unless Spanish, Catalan, French, or German barcodes miss.
Laptop or self-hosted Node server Express proxies /api/books/* automatically. Add GOOGLE_BOOKS_API_KEY in a local .env file (Option A).
Static GitHub Pages / Phone PWA Browser queries Open Library + public Google Books directly. Deploy a free 20-line Cloudflare Worker URL and paste it in Settings (Option B).
Never commit your own API key to a public GitHub repo Anything inside VITE_* or committed source files is visible to every visitor and shares your personal daily quota. Keep keys in untracked .env files or a private Worker secret.

2. Get a Free Google Books Key (60 Seconds)

1

Enable Books API

In Google Cloud Console, create a project and click Enable on Books API.

2

Create Credentials

Open APIs & Services → Credentials → + Create Credentials → API key.

3

Restrict to Books API

Under API restrictions, choose Restrict key and check Books API only → Save.

3. Option A — Local / Self-Hosted Server (.env)

Create .env in the project root (already ignored by Git) and restart npm run dev:

GOOGLE_BOOKS_API_KEY="AIzaSyYourPrivateGoogleBooksKey"
Browser Request GET /api/books/volumes?q=isbn:9788426132277
→
Express Proxy Result Attaches GOOGLE_BOOKS_API_KEY on the server and returns merged cover + metadata.

4. Option B — GitHub Pages / Phone PWA Proxy

Static hosts (like GitHub Pages) have no Node server. A free Cloudflare Worker holds your secret key and gives you an HTTPS URL you can paste on your phone in Settings → Catalog Lookup Providers (saved only on that device, never in JSON backups).

Paste this Worker script in Cloudflare, add secret GOOGLE_BOOKS_API_KEY + variable ALLOWED_ORIGIN (e.g. https://yourname.github.io), and deploy:

export default {
  async fetch(request, env) {
    const origin = request.headers.get('Origin') || '';
    const cors = {
      'Access-Control-Allow-Origin': env.ALLOWED_ORIGIN || origin || '*',
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
    };
    if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: cors });

    const incoming = new URL(request.url);
    const upstream = new URL('https://www.googleapis.com/books/v1/volumes');
    for (const key of ['q', 'maxResults', 'printType']) {
      if (incoming.searchParams.get(key)) upstream.searchParams.set(key, incoming.searchParams.get(key));
    }
    if (env.GOOGLE_BOOKS_API_KEY) upstream.searchParams.set('key', env.GOOGLE_BOOKS_API_KEY);

    const res = await fetch(upstream.toString(), { headers: { Accept: 'application/json' } });
    return new Response(await res.text(), {
      status: res.status,
      headers: { ...cors, 'Content-Type': 'application/json; charset=utf-8' },
    });
  },
};
