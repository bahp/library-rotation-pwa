# Drop-in Phone Screenshots (`390×844` Recommended)

The HTML documentation in `public/docs/` renders phone-sized interface frames with built-in miniature UI previews.

To replace any preview frame with a real screenshot from your phone or browser DevTools (`iPhone 12/13/14 — 390×844`), save PNG files into this folder using these exact names:

- `home-shelf.png` — Home active shelf & seasonal/swap alert (`index.html`)
- `scan-barcode.png` — Barcode camera viewfinder & lookup card (`index.html`)
- `rotations-edit.png` — Rotations view with pen inline rename & presets (`index.html`)
- `play-games.png` — Play view with Book Hunt & Storytime Picker (`index.html`)
- `settings-providers.png` — Settings Catalog Lookup Providers card (`configuration.html`)

No HTML edits are required: as soon as a matching `.png` file exists here, the phone frame displays it automatically.
